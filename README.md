# Skill Update FS

A Codex skill for checking source files and updating CMS or investor-relations (IR) HTML snippets, chart data, or mismatch reports.

## Contents

- `SKILL.md` — workflow and rules for workbook-backed data updates, shareholder content, Word-to-HTML conversion, and UAT checks.
- `agents/openai.yaml` — skill display name and default prompt.
- `references/snippet-patterns.md` — common workbook and snippet mappings.

## Install

Copy this folder into your Codex skills directory, typically `$CODEX_HOME/skills/skill-update-fs`, then restart or refresh Codex skills.

Invoke it with `$skill-update-fs`.
